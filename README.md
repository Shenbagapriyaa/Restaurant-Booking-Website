
## Restaurant Booking Platform

This is a full-stack web application built to make discovering restaurants and booking tables simple and secure. It allows users to browse through featured dining spots, save their favorites, and keep track of their reservations in one place.

Key Features:
* User Authentication: Secure login and sign-up with persistent sessions.
* Restaurant Discovery: Browse and filter featured venues.
* Favorites: Easily save and manage your preferred restaurants.
* Notifications: Keep updated on your booking status.
* Responsive Design: A clean, modern interface that works great on all devices.

# Tech Stack

Frontend: React, TypeScript, Vite, and Axios
Backend: Node.js, Express, and RESTful APIs
DB: Mongodb

## How to Get Started

1. Clone the repository to your local machine.
2. Install the necessary packages for both the frontend and backend folders using npm install.
3. Set up your environment variables by creating a .env file inside your backend folder (ensure you include your database URI and secret keys).
4. Start your backend server by running node server.js inside the backend folder.
5. Start your frontend development server by running npm run dev inside the frontend folder.
